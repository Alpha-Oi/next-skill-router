# Contributing

Спасибо за интерес к `next-skill-router`!

## Процесс

1. Fork → branch → PR.
2. Один PR — одна задача.
3. Обязательно: тесты, документация, обновление ADR при архитектурных изменениях.

## Изменения в спецификации

Любое изменение в `spec/` требует RFC Issue с меткой `spec` и минимум
7 дней публичного обсуждения.
