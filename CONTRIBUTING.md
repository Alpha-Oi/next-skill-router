# Contributing

Thanks for your interest in next-skill-router!

## Start here

1. Read the [project philosophy](./README.md#design-principles).
2. Skim the [ADRs](./docs/adr/) — they explain key decisions.
3. Open an issue or discussion before writing a large PR.

## Process

1. Fork -> branch -> PR.
2. One PR = one concern.
3. Required: tests, docs, ADR update if the change is architectural.

## Style

- TypeScript strict mode.
- ESLint + Prettier (auto-configured).
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/).

## Spec changes

Any change in spec/ requires:

1. An RFC issue with the spec label.
2. At least 7 days of public comment.
3. Approval from two maintainers.

## Local development

```bash
git clone https://github.com/Alpha-Oi/next-skill-router
cd next-skill-router
npm install
npm test
```
